
# Firmware

## Overview

This directory contains the actively developed firmware for the Arduino-based line-following robot.

The development builds upon the competition version documented in Version 2. The goal is to improve the robot's control logic, line tracking, obstacle avoidance, and overall reliability.

## Current Development

The firmware is the main development workspace for future improvements. Changes are tested and refined before being considered part of a new documented version.

## Hardware

The firmware is designed for the following hardware:

- Arduino Uno R3
- 3 × TCRT5000 infrared sensor modules
- 4 × HC-SR04 ultrasonic distance sensors
- L298N motor driver
- 2 × DC motors

For wiring details, see [Hardware Notes](../hardware/).

## Version History

- [Version 1](../docs/version-1/) — Original school project.
- [Version 2](../docs/version-2/) — Final competition version used at Unga Forskare.

## Development Goals

Planned improvements include refining sensor handling, improving line tracking and obstacle avoidance, and testing the robot's reliability under different conditions.

Completed improvements and test results will be documented as development progresses.
