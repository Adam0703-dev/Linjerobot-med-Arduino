# Version 1 historical record

Version 1 is preserved as a historical record of the original project developed as part of my upper-secondary school thesis (*gymnasiearbete*).

It documents the initial design, implementation, and development process of the robot. Keeping this version separate from later iterations makes it possible to trace the project's evolution and compare the original approach with subsequent improvements.

This version is retained in its original form for reference and documentation. Further development is focused on Version 2.
