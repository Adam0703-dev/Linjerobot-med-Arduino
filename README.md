
# Linjerobot med Arduino

## Overview

This project documents the development of an Arduino-based line-following robot capable of detecting and navigating along a line, identifying obstacles, and maneuvering around them before returning to the line.

The project is divided into multiple versions to document the robot's development, from the original school project to the improved competition version.

## Versions

### Version 1 – Original Project

The initial version of the robot, developed as part of my upper-secondary school thesis (*gymnasiearbete*).

- Focus: Initial robot design and implementation.
- Documentation: Original thesis report and modell picture.
- [View Version 1](./docs/Version-1/)

### Version 2 – Competition Version

The version developed for the Unga Forskare competition. This version serves as the foundation for further development and improvements.

- Focus: Robot behavior, control logic, and obstacle avoidance.
- Documentation: Final competition code, modell picture, flowchart and schematics.
- [View Version 2](./docs/Version-2/)

## Hardware

The project uses Arduino-based electronics, including:

- Arduino Uno
- Infrared (IR) sensors
- Ultrasonic distance sensors
- DC motors
- Motor driver

The exact hardware configuration may vary between versions.

## Future Development

Planned improvements may include refining the control logic, improving obstacle avoidance, testing reliability, and documenting performance.
