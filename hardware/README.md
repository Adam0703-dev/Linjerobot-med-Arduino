# Hardware notes

The Version 2 source material identifies an Arduino Uno, two DC motors, a motor driver, three IR sensors, and three ultrasonic sensors. The motor-driver model is not specified in the Version 2 poster or sketch.

The repository does not yet include a verified wiring diagram or bill of materials. Add those after checking the physical robot. Until then, use the pin definitions in the firmware as a reference for the imported sketch and verify them against the robot.
